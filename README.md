# jsslug

Slugify with unicode normalisation.

```
import { slugify } from "./index.js";
```

## layout

- `index.js`
- `index.test.js`  — tests
- `package.json`

## use

Node 18 or newer, ESM only.

```
git clone https://github.com/CodingWithFardin/jsslug.git
cd jsslug
```

Tests: `index.test.js`. A change that breaks one is usually the wrong change.
